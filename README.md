# Growing Cat v2.0 (고양이 키우기)

Python과 Pygame으로 만든 싱글플레이 고양이 육성 게임입니다. 행복·청결은 높게, 배고픔·피로는 낮게 관리하며 고양이를 성장시키고 미니게임과 대회에 도전합니다. 학교 프로젝트의 기존 이미지·사운드·폰트를 그대로 사용하며, v2.0에는 신규 에셋을 추가하지 않았습니다. 새로운 표시와 타이밍 게임은 Pygame 도형·텍스트로 구현했습니다.

## 실행

Python 3.10 이상과 Pygame이 필요합니다.

```bash
pip install pygame
python app.py
```

저장소 폴더에서 실행하세요. 처음에는 난이도(쉬움·보통·어려움), 성격(활발함·차분함·냥냥함), 이름을 선택합니다. 정상적인 저장 파일이 있으면 자동으로 이어서 시작합니다.

## 기본 조작과 육성

- 메인 화면 오른쪽 화살표: 먹이·놀기·청소·수면·진화·특별 돌봄.
- 왼쪽 화살표: 설정·미니게임·대회·상점·가방·업적·앨범·오늘의 활동.
- **다음 시간**: 아침 → 밤 → 다음 날 아침. 실제 달력이 아니라 게임 내 일차를 기준으로 진행합니다.
- 무료 돌봄 4종과 미니게임 5종은 **각 아침·밤 시간대에 한 번씩** 사용할 수 있습니다. 정상 모드와 도전 모드는 같은 사용 횟수를 공유합니다. 사용 기록은 재실행해도 유지되며 다음 시간대에 초기화됩니다.
- **ESC**: 메인 화면에서 일시정지, 다른 화면에서는 복귀·취소. 미니게임 도중 중단하면 보상과 완료 기록 없이 해당 시간대의 시도만 사용합니다.
- **F12** 또는 일시정지 메뉴: 사진 촬영. 앨범에서 확인하고 개별 삭제할 수 있습니다.
- 목록 화면의 이전·다음 버튼, 좌우 방향키, 휠: 페이지 이동. 업적·앨범 목록은 휠로 스크롤합니다.
- 게임 오버: **R**로 시작 화면 복귀, **ESC**로 종료.

배고픔·피로가 100에 도달하면 사망하고, 행복·청결이 0에 도달하면 가출합니다. 난이도는 스탯 변화·가격·보상·미니게임 조건에, 성격은 선호 돌봄과 일부 회복·소모 효과에 영향을 줍니다.

기존 진화 4단계를 유지합니다. 비용은 보통 난이도 기준이며 다른 난이도에는 기존 보정이 적용됩니다.

| 진화 | 조건 | 비용 |
|---|---|---:|
| 아기 → 성묘 | 7일차 이상 | 100코인 |
| 성묘 → 사자 | 21일차 이상, 고기 1개, 행복·청결 75 이상 / 배고픔·피로 25 이하 | 500코인 |
| 사자 → 공룡 | 35일차 이상, 뼈 1개, 행복·청결 80 이상 / 배고픔·피로 15 이하 | 1,000코인 |

조건을 만족하면 진화 메뉴에서 진행하거나 새로운 아침에 자동 진화합니다.

## 기분·친밀도·특별 돌봄

기분은 기존 스탯을 바탕으로 행복함·평온함·피곤함·배고픔·불편함·심심함으로 표시합니다. 기분·성격·진화·친밀도에 맞는 대사가 나오며 최근 대사의 반복을 줄입니다. 기존 이미지를 이동·확대·축소·투명도로 반응시킵니다.

친밀도는 0~1,000이며 낯선 사이 → 익숙한 사이(100) → 친구(300) → 단짝(600) → 가족(1,000)으로 올라갑니다. 같은 기본 행동으로 얻는 친밀도는 시간대별로 제한합니다.

특별 돌봄은 하루 한 번, 조용히 곁에 있기·빗질·숨바꼭질·기대 쉬기 중 선택합니다. 선택 화면에서 효과와 추천 행동을 확인하고 숫자 1~4 또는 클릭으로 실행합니다. 같은 행동을 여러 날 연속 선택하면 효과가 감소하며, 나쁜 컨디션에서는 일부 행동을 제한합니다.

## 일일 활동과 성장 기록

**오늘의 활동**에서 이벤트와 일일 미션을 확인합니다.

- 새 날마다 35% 확률로 이벤트를 정합니다. 이벤트 여부·선택 결과는 저장되어 재실행으로 다시 추첨하거나 보상을 반복할 수 없습니다.
- 이벤트에는 2~3개 선택지가 있고, 성장 단계·성격·친밀도·생존 일수에 따른 특별 이야기도 있습니다. 숫자 1~3 또는 클릭으로 선택합니다. 미뤄 둔 이벤트는 다음 시간으로 넘어가기 전에 해결해야 합니다.
- 돌봄·미니게임·구매·고양이 클릭으로 미션을 진행합니다. 숫자 1~3 또는 받기 버튼으로 완료 보상을 수령합니다.
- 세 미션의 보상을 모두 받으면 연속 달성에 반영됩니다. 연속 보너스와 7일마다 기존 사료 보상이 있으며 같은 보상은 한 번만 받습니다.
- 하단 **육성 기록**에서 생존·돌봄·구매·획득 코인과 미니게임·대회·이벤트·미션 통계를 조회합니다. 진화·친밀도 단계·생존 목표를 최근 60개 성장 기록에 남깁니다.

## 미니게임 5종

선택 화면에서 정상/도전 모드를 바꿀 수 있습니다. 다섯 번째 타이밍 놀이는 두 번째 페이지에 있습니다. 난이도별 속도·시간·판정 범위·목표를 조정하며 기존 4종의 정상 규칙을 유지합니다.

| 게임 | 조작 | 도전 모드 |
|---|---|---|
| 장애물 피하기 | Space 점프 | 목표 거리 쉬움 250m / 보통 350m / 어려움 450m, 어려움은 단일 점프 |
| 메모리 게임 | 카드 클릭 | 2~3단계, 번호 순서 매칭·남은 카드 재배치, 재배치 후 잠깐 다시 공개 |
| 고양이 따라가기 | 보여준 칸을 순서대로 클릭 | 더 긴 순서, 정순·역순 교대 |
| 레이저 포인터 | 움직이는 점 클릭 | 점수와 콤보·적중 수·정확도 목표 모두 충족 |
| 타이밍 놀이 | Space 또는 클릭 | 움직이는 선을 초록 판정 영역에서 멈추기, 가운데 금색은 완벽 판정 |

**최고 기록**에서 플레이·승리·도전 성공·게임별 기록을 확인합니다. **도전 과제**에는 게임당 첫 성공·특별 목표·도전 완주 3개, 총 15개 목표가 있습니다. 해금 후 받기 버튼 또는 숫자 1~3으로 특별 보상을 받습니다. 일반 플레이 보상과 별도로 코인·기존 아이템을 지급하며, 목표당 한 번만 수령합니다.

## 대회·리그·업적

기존 귀여움·깔끔함·먹방·사냥·체력·행운 대회가 3일마다 순환하며 대회 당일 한 번 참가합니다. 참가비·일반 보상·점수 계산은 기존 난이도 규칙을 유지합니다. **S등급을 우승**으로 기록하고 A/B/C등급도 참가 횟수와 최고 점수에 반영합니다.

S/A/B/C등급은 각각 5/3/1/0 리그 포인트를 줍니다. 포인트와 누적 우승 조건을 모두 충족하면 진급하고, 진급 보상은 단계마다 한 번 지급합니다. 온라인 서버나 랭킹은 사용하지 않습니다.

| 리그 | 누적 포인트 | 누적 우승 | 진급 보상 |
|---|---:|---:|---:|
| 브론즈 | 0 | 0 | 없음 |
| 실버 | 20 | 1 | 25코인 |
| 골드 | 50 | 3 | 40코인 |
| 플래티넘 | 100 | 8 | 60코인 |
| 마스터 | 180 | 15 | 90코인 |

**트로피 도감**에서 6종의 최고 등급·점수·참가·우승·최근 기록을, **전체 기록**에서 최근 30개 참가 결과를 페이지로 조회합니다. 누적 5/10승과 3/5연승 목표도 표시합니다. 기존 업적에 친밀도·이벤트·미션·미니게임 도전·리그 업적 15개를 추가했으며 해금 현황과 점수를 업적 화면에서 확인합니다.

## 보상과 저장

기존 난이도 보정을 유지하며 일반 미니게임 보상에는 한 번만 적용합니다. 추가 일일 미션은 하루 전체 달성 시 6~8코인, 이벤트 코인 효과는 최대 +8/-5로 제한합니다. 타이밍 놀이의 일반 보상은 보정 전 최대 40코인입니다. 미니게임 특별 목표는 모두 수령해도 총 225코인, 리그 진급은 총 215코인으로 고양이 한 마리의 진행 기록에 한 번만 지급합니다.

Windows 저장 위치는 `%APPDATA%/growing-cat/`이며 다른 운영체제에서는 홈 폴더 아래 `growing-cat/`입니다.

- `save.dat`: HMAC 서명 저장 파일. Windows에서는 기존 DPAPI 방식으로 HMAC 키를 보호합니다.
- `achievements_save.json`: 기존 업적 해금·누적 기록.
- `album/`: 사용자가 촬영한 사진.

기존 저장 형식과 신규 필드가 없는 세이브도 불러옵니다. 무료 행동·이미지·친밀도·이벤트·미션·기록은 기본값과 기존 이력으로 호환 처리합니다. 과거 이력만으로 정확히 알 수 없는 우승 횟수는 확인 가능한 최소 횟수만 복원합니다. 이전 행동·코인 통계는 업데이트 시점부터 기록합니다. 고양이 이미지 선택은 상대 경로로 저장하며 누락 시 기존 단계의 이미지를 대체 선택합니다.

대회 참가, 이벤트 선택, 미션·특별 목표 보상은 저장 실패 시 적용 내용을 복구합니다. 무결성 검증 실패 시 저장을 자동으로 덮어쓰지 않고 시작 화면으로 돌아갑니다. **새 게임 시작은 현재 고양이 저장을 교체**하므로 기존 진행을 보관하려면 저장 폴더를 먼저 백업하세요. Windows DPAPI 키는 해당 사용자 환경에 종속되므로 다른 PC로 이동할 때 저장 파일만 복사하면 불러오지 못할 수 있습니다.

설정의 데이터 초기화에는 확인·취소가 있고 고양이 진행·신규 기록·업적을 함께 초기화합니다. 사진 앨범은 삭제하지 않습니다. 사진 삭제는 앨범의 별도 확인으로 처리합니다.

## 주요 코드

- `app.py`, `cat.py`, `state.py`, `evolution.py`: 메인 화면·돌봄·성장·저장 연동
- `game.py`, `minigames/`, `minigame_records.py`, `minigame_challenges.py`: 게임·통계·특별 목표
- `daily_events.py`, `daily_missions.py`: 일일 이벤트·미션·보상
- `competition.py`, `competition_ui.py`: 대회·통계·리그·도감
- `growth_records.py`: 육성 통계·성장 이력·조회 화면
- `shop.py`, `bag.py`, `items.py`: 기존 아이템과 페이지 UI
- `achievements.py`, `achievements_ui.py`: 업적 해금·목록·점수
- `save.py`, `save_key_store.py`: 기존 저장 서명·키 보호
- `pg_utils.py`: 리소스 로딩과 정적 이미지 캐시

개발 점검은 별도 테스트 파일 없이 문법, Pygame 더미 화면 실행, 저장 호환·무결성·보상 중복·실패 복구와 주요 흐름을 확인했습니다. 실제 Windows 화면·입력·DPAPI 실행 검증은 별도로 필요합니다.
